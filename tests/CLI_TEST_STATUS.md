## 主要问题分析

### 1. Mock路径问题
- **问题**: 许多测试使用了不存在的mock路径
- **影响**: 导致大量`AttributeError`
- **解决方案**: 需要检查实际的导入路径和类名

### 2. CLI参数格式问题
- **问题**: 测试中的CLI参数格式与实际命令不匹配
- **影响**: 导致参数解析错误
- **解决方案**: 需要重新调整命令行参数格式

### 3. 文件验证逻辑
- **问题**: 测试中的文件验证逻辑过于严格
- **影响**: 导致许多基本测试失败
- **解决方案**: 需要改进文件mock策略

## 成功的测试策略

基于`test_prune.py`的成功经验，以下策略有效：

### 1. 正确的Mock路径
```python

```

### 2. 灵活的断言

### 3. 简化的测试逻辑
